# Multilingual Fake News Detection

Machine Learning project for detecting fake news using Natural Language Processing (NLP) and multilingual Indian-language datasets.

## Datasets

1. IFND – Indian Fake News Dataset
2. Zenodo Multilingual Indian Fake News Dataset
3. FND-LRIL – Fake News Detection for Low-Resource Indic Languages

## Objective

To develop a multilingual fake news detection system using a single NLP model trained on multiple Indian-language datasets.
